# AURORA

**Augmenting Underrepresented Rare-disease Observations using Realistic Artificial imaging**

MediSyn toolkit | Final Year B.Tech Project (Data Science / AI-ML) | First research paper

## Overview

AURORA is a generative-AI system that creates high-fidelity **synthetic** X-ray / MRI
images of underrepresented (rare) disease classes. Its purpose is to augment
imbalanced medical imaging datasets so that downstream disease-detection models
can be trained with less bias and higher minority-class recall, **without ever
requiring access to real patient data**.

The companion demo app is called **MediSyn**.

## Research question

> To what extent can synthetic minority-class chest X-rays (TB) generated by GANs
> and diffusion models improve TB-detection performance when real training data is
> limited, and how do fidelity (FID) and downstream utility (minority recall)
> trade off across generative families and real-data budgets?

## Features

- Privacy-preserving: no real patient data is shared or stored
- GAN-based synthetic image generation (DCGAN / WGAN-GP)
- Diffusion comparison arm (DDPM, on Kaggle/Colab)
- Quantitative evaluation with FID scores
- Downstream classifier improvement demonstration (ResNet-18)
- Streamlit demo UI (MediSyn)

## Quick Start

### Installation

```bash
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
```

For the diffusion arm (Kaggle/Colab):

```bash
pip install -r requirements-diffusion.txt
```

### Training the GAN

```bash
python src/gan/train_gan.py --config configs/dcgan.yaml
```

### Running the Demo

```bash
streamlit run app/streamlit_app.py
```

## Project Structure

```
AURORA/
  data/                    # Datasets (raw/, processed/, synthetic/) [gitignored]
  models/                  # Saved model checkpoints [gitignored]
  src/
    data_loader.py         # Data loading & preprocessing
    gan/                   # GAN modules (generator, discriminator, losses, train)
    classifier/            # ResNet-18 classifier + training
    evaluate/              # FID + metrics
    utils/                 # Seeding, logging, guards, visualization
  configs/                 # YAML configs (dcgan, classifier)
  app/                     # Streamlit demo (MediSyn)
  tests/                   # Unit tests
  PROJECT_DISCOVERY.md     # Discovery report
  EXPERIMENT_PLAN.md       # Experiment protocol
```

## Dataset

Primary: Kaggle TB Chest X-ray Database (3500 Normal / 700 TB, 5:1 imbalance).

Also supports: NIH Chest X-ray14, CheXpert (Stanford).
