# AURORA — Experiment Plan (Draft)

Companion to `PROJECT_DISCOVERY.md`. Defines the exact protocol for the paper's
experiments so that results are reproducible and comparable.

## 1. Research question (final)
To what extent can synthetic minority-class chest X-rays (TB) generated by
GANs and diffusion models improve TB-detection performance when real training
data is limited, and how do fidelity (FID) and downstream utility (minority
recall) trade off across generative families and real-data budgets?

## 2. Data
- Source: Kaggle "Tuberculosis (TB) Chest X-ray Database" (Qatar Univ.).
- Classes: Normal (3500), TB (700 publicly available). Imbalance 5:1.
- Split: 70 / 15 / 15 (train/val/test), stratified, seed 42. Saved to
  `data/splits.json`.
- Image size: 128×128 grayscale, normalized to [-1, 1].
- We stay with the public 700 TB images for reproducibility.

## 3. Models
- **Generators:** DCGAN, WGAN-GP (existing), DDPM conditional (new, on
  Kaggle/Colab).
- **Downstream classifier:** ResNet-18 (real torchvision), 2 classes, class
  weights, early stopping. Identical hyperparameters across all conditions.

## 4. Independent variables
| Var | Levels |
|---|---|
| Generative family | DCGAN, WGAN-GP, DDPM |
| Real TB budget | 50, 100, 200, 400, 700 |
| Synthetic ratio | 0× (none), 0.5×, 1×, 2× minority deficit |
| Augmentation type | none, classical (flip/affine), generative |

## 5. Dependent variables
- FID (synthetic TB vs real TB test split), using standard ImageNet Inception.
- Classifier: accuracy, precision, recall (minority/TB), F1, AUC-ROC.
- Training time, samples/sec (for cost discussion).

## 6. Baselines / controls
1. No augmentation (real data only) — lower bound.
2. Classical augmentation only — isolates generative value.
3. Upper bound: balanced real data (if 3500/3500 available via NIAID agreement).

## 7. Protocol
- 3 seeds (42, 123, 999); report mean ± std.
- Fixed 70/15/15 split; no leakage of test into training/augmentation.
- Synthetic images are generated from the training split only.
- Same classifier hyperparameters and early-stopping across conditions.
- Pre-registered success criteria:
  - ≥ 15% relative gain in minority recall vs. no-augmentation baseline.
  - FID ≤ 80 on at least one generative family.
  - No condition where augmentation *hurts* recall by > 2%.

## 8. Ablations
- Resolution: 64×64 vs 128×128 (GAN only).
- Loss: BCE vs WGAN-GP.
- Number of synthetic samples: saturation curve.
- Conditioning: unconditional vs class-conditional generation.

## 9. Deliverables
- Result tables (CSV) + figures (FID vs budget, recall vs budget, trade-off
  scatter).
- Grad-CAM visualizations comparing real vs synthetic-trained models.
- Kaggle/Colab notebooks reproducing GAN and diffusion training.
- MediSyn Streamlit demo updated with best model + generated samples.
- Paper sections: methods, results, ablations, discussion, limitations.

## 10. Reproducibility checklist
- [ ] All seeds recorded in configs.
- [ ] Configs versioned in git.
- [ ] Datasets referenced by Kaggle slug + version.
- [ ] Trained checkpoints uploaded (Zenodo/Kaggle dataset) or regenerable.
- [ ] Notebooks run top-to-bottom on a fresh Kaggle/Colab session.
- [ ] Requirements files: `requirements.txt` (GAN) + `requirements-diffusion.txt`.

## 11. Risks (from discovery)
- FID on small medical sets is noisy → use KID as secondary metric.
- Diffusion on 6 GB GPU → start at 64×64 or use Kaggle.
- Scope creep → timebox per timeline in discovery doc.
